## Phase 1 — Contract tests and markup decoupling → T-UT02, T-UT03

Split for parallel worktrees (orchestrator mode, ADR-0066). Each item, for its routes:
- writes contract tests (`@covers`) for status, redirects, `HX-*` headers, CSRF, auth/authz (including cross-user access returns 404), DB and `audit_log` effects;
- rewrites its markup-coupled assertions in `tests/integration/web/` through the UI map, or splits them into contract + UI-map assertions;
- removes its entries from both allowlists (T-UT02, T-UT03);
- adds `id` / `data-testid` hooks to old templates only where role/label is ambiguous, listed in the handoff.

- **Acceptance (each item)**: its allowlist entries are gone; its tests pass; no test body asserts on a class name or copy; existing behaviour unchanged (any real bug becomes a strict `xfail` with a new task id).
- **Validation (each item)**: `just test tests/contract tests/integration/web/<its files>`
