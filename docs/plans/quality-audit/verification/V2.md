## Method

- Independence rule followed: only id, title, severity and Location(s) were read from the tracks before forming a verdict.
  Description/Evidence/Impact sections and `repro/<track>/` scripts were not opened. For H1 I used the raw
  `repro/H1/gh_api/*.json` API output as data only.
- Scope: every Critical/High in D, E, G, H1, H3 (D-01, E-03, E-04, E-05, G-01, H1-01, H1-02; H3 has none),
  plus a random sample of Mediums.
- Medium population (20): D-02, D-06, E-01, E-02, E-06, G-02, G-03, G-05, G-06, G-08, G-09, G-10, G-13, G-14, G-16,
  H1-03, H1-04, H1-05, H1-06, H3-01.
  `random.seed(22); sorted(random.sample(mediums, 5))` -> **D-02, E-06, G-02, G-05, G-16** (25%, above the 20% floor).
- Own repros (scratch, in-memory DB; no server started, no network):
  - `repro/verify/V2/g01_fx_relative_url.py` -> `.out`
  - `repro/verify/V2/d02_overflow.py` -> `.out`
- Operator facts applied (2026-11-19): prod has only PLN accounts, one active user, more users soon. Latent wrong-money = High.
