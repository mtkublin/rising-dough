# Segmented

Segmented control for ranges, tabs and on/off choices; the selected option is ink.

On the base board: selected = ink; also used for tabs and on/off choices (no switches).

Classes (from `components/bundle.css`): `.rd-segmented`, `.rd-tabs`.

Source: the *segmented · tabs* section of the base package's `components.html`; the markup in the preview is the markup the app ships. Use the classes, never restyle them with literal values; both themes come from the tokens.
