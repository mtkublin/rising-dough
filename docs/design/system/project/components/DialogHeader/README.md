# DialogHeader

Dialog headers: bake band with hero value, slim band with action, confirm without band.

On the base board: amount dialogs: orange band + hero value · other dialogs: slim band with action · object · confirms: no band. Live versions: see the overlay pages..

Classes (from `components/bundle.css`): `.rd-dialog`, `.rd-icon`, `.rd-btn`.

Source: the *dialog headers* section of the base package's `components.html`; the markup in the preview is the markup the app ships. Use the classes, never restyle them with literal values; both themes come from the tokens.
