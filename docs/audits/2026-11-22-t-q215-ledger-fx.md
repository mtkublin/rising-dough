# Frontend audit: T-Q215 ledger strips convert across currencies (2026-11-22)

Change: `/ledger?view=planned` and `/ledger?view=recurring` strips now sum every leg in the base currency via the FX hub
(ADR-0006, ADR-0139). Template change: `ledger/index.html` planned strip gains `aria-label="Planned items summary"` (locator
for the ui_map); no literal `PLN`, no arithmetic in the template (values come from `services/ledger_totals.py`).

Method: Playwright (chromium) against a live server on a scratch temp DB (never `data/budget.sqlite`): PLN account, EUR
account, EUR->PLN rate 4.30, monthly rules and planned rows (PLN income 5,000.00; EUR expense 100.00).
