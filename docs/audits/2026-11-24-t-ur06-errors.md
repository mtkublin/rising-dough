## Findings

None blocking (STATUS CLEAN). Observations for the orchestrator:
1. An unrouted URL (`/does-not-exist`) returns bare JSON `{"detail":"Not Found"}`, not the new 404 page, because no handler maps Starlette `HTTPException`/405. Same on BASE (no `HTTPException` handler in `errors.py`), so not a regression; the 404 page is reached only via `NotFoundError`. Likewise some real "not found" routes (`/transactions/999999/edit`) return a form fragment with 404 status. Follow-up candidate.
2. The 422 page is not reached by `POST /transactions` bad amount (the router re-renders the form fragment); the real full-page 422 path is `ParamError` (bad query param).
3. The old `base.html` HTMX flash is intact (T-UR15 still pending).
